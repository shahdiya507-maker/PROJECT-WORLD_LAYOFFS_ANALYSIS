# 🌍 World Layoffs Analysis

## 📌 Project Overview

This project analyzes global layoffs using an end-to-end data analytics workflow.

The project covers data cleaning, exploratory data analysis, visualization, and dashboard development using **Excel, SQL, and Power BI**.

The analysis focuses on identifying patterns and trends in layoffs across companies, industries, countries, locations, funding stages, and time periods.

---

## 🎯 Objectives

- Clean and prepare the raw layoffs dataset
- Perform exploratory data analysis using Excel and SQL
- Analyze layoffs across different dimensions
- Identify important trends and patterns
- Create meaningful visualizations
- Build an interactive Power BI dashboard
- Generate actionable insights from the data

---

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data cleaning, pivot tables, charts, and analysis
- **MySQL** – SQL-based exploratory data analysis
- **Power BI** – Interactive dashboard and data visualization

## 🔍 Key Insights

- Approximately **383K layoffs** were recorded in the dataset.
- The largest single layoff event involved **12,000 employees**.
- Layoffs increased significantly during **2022 and 2023**.
- The **United States** recorded the highest number of layoffs.
- **Post-IPO companies** accounted for a large share of reported layoffs.
- Several major technology companies recorded layoffs in the thousands.
- Industries such as **Consumer, Retail, Transportation, Finance, and Healthcare** were significantly affected.
